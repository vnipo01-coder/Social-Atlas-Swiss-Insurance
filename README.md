# SOCIAL ATLAS

Interaktive Lernplattform zur Schweizer sozialen Sicherheit, Sozialhilfe aller 26 Kantone und zu den fünf Nachbarländern.

## Start

Die Web-App besteht aus `index.html`, `style.css` und `app.js`. Sie kann über GitHub Pages veröffentlicht werden.

**Hinweis:** Didaktischer Prototyp. Keine Rechtsberatung; kantonsspezifische Beträge und Anspruchsvoraussetzungen sind nicht vollständig hinterlegt.
